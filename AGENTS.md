# Catchup

A work-in-progress Google Classroom MCP written in Go.

## Documentation

All architectural documentation is located in the `@docs` folder.

## Project Conventions

- Git commit messages must follow the [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/#specification) specification.
- Commit messages should ideally be single-line statements without lists or co-author trailers.
- Do not add comments to generated code unless explicitly specified.

## Go Practices

Follow established Go patterns and designs for implementations. A few examples are:

- Error messages must follow standard Go error conventions.
- HTTP APIs must adhere to REST standards.
- Docstrings must be Go style.
